## 🌱 About Us

**ITrys (pronounced: /aɪˈtriːs/)** is an **open, neutral, and sustainable** open source collaboration organization dedicated to building enterprise-grade application development.

"ITrys" originates from "**I Try**" —
We believe every attempt is the starting point of innovation.
Every small effort deserves encouragement; every sincere contribution deserves to be seen.

Whether you're a beginner or a seasoned expert, as long as you're willing to act and eager to share, this is your stage.
The essence of ITrs is to gather countless "I Try"s into a world-changing "**We Did**".

---

### 🌟 Our Mission

- ✅ **Lower the barrier to participation**: Help everyone transition from "using open source" to "making open source," making the first PR no longer daunting;
- ✅ **Incubate practical open source**: Focus on high-quality, reusable development frameworks, tools, and infrastructure that address real developer pain points.
- ✅ **Co-build the ecosystem**: Foster a friendly, inclusive, and supportive community culture, making sharing a habit and co-building the norm, driving sustainable open source development.

## 🛠️ Business-Friendly

ITrys explicitly supports the following **legitimate and sustainable** open source business models:

| Model | Description | Example |
|-------|-------------|---------|
| **Open Core** | Open source base features + closed-source premium features | GitLab CE / EE |
| **Managed Service (SaaS)** | Hosted operations with SLA support | MongoDB Atlas |
| **Custom Development** | Accepting enterprise-paid customization requests | Freelance developers |
| **Education/Research Open Source** | Long-term hosting and handover for university projects | Lab graduation projects |
| **Dual License** | OSI-approved license + commercial license (must be clearly stated) | |

> 🔒 **Principle**: The open source portion must be **buildable, runnable, and feature-complete** — not a "demo version."

- **Prohibited behaviors**:
  - ❌ Intentionally making the open source edition unusable (e.g., disabling critical APIs)
  - ❌ Blurring commercial boundaries (e.g., claiming "premium is more stable" without evidence)

## 🚀 How to Join?

1. **Ensure your project meets the [Admission Criteria](https://github.com/itrys/community/GOVERNANCE.md#4-项目准入标准)**
   - Uses MIT / Apache-2.0 license
   - Can be independently built and run
   - Accepts reasonable community contributions (e.g., documentation, bug fixes)

2. **Submit an Application**
   → [Click to Create a "Project Admission Application" Issue](https://github.com/itrys/community/issues/new?template=project_proposal.yml)

3. **After Approval**
   - Receive the `ITrys Certified` badge
   - Reports published to [compliance-reports](https://github.com/itrys/community/compliance-reports/)
   - Project listed in [awesome-itrys](https://github.com/itrys/community/awesome-itrys/)

### 💡 About Forked Projects
- ITrs accepts applications for enhanced fork projects of existing open source projects.
- Before applying, the project must:
    - Have completed "de-forking" (displayed as an independent repository on the hosting platform)
    - Contain significant original enhancements (e.g., new features, localization, performance optimization)
    - Acknowledge the original project in its README (reflecting the open source spirit)
    - ITrs does not accept forked projects with only minor modifications or inactive maintenance.
